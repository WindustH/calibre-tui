# Calibre TUI

Терминальный интерфейс для поиска по библиотеке Calibre: найденные книги можно открыть или вывести их пути для shell-скриптов.

## Возможности

- Мгновенный поиск по мере ввода по названию, авторам, серии, форматам и тегам. Должны совпасть все слова, разделённые пробелами.
- Поиск по другим письменностям с латинской клавиатуры: китайский — пиньинем (включён по умолчанию), японская кана — ромадзи, русский — транслитом, а немецкий, французский и испанский — без диакритических знаков.
- Можно выбрать несколько книг и открыть их, скопировать пути или вывести пути и выйти, чтобы использовать их в конвейере shell.
- Для каждого формата можно задать свою программу, например `zathura` для PDF; иначе используется приложение по умолчанию.
- Сортировка по любому полю сочетаниями `Ctrl+S` или командой `sort`.
- Колонки, сочетания клавиш (включая последовательности из нескольких клавиш с подсказками) и цвета настраиваются в TOML-файлах с комментариями.
- Работает при запущенном Calibre; библиотека только читается и никогда не изменяется.

## Установка

Arch Linux (AUR):

```bash
yay -S calibre-tui-bin   # готовый бинарный файл
yay -S calibre-tui       # последний релиз, сборка из исходников
yay -S calibre-tui-git   # последняя версия из git, сборка из исходников
```

Homebrew:

```bash
brew install WindustH/tap/calibre-tui          # готовый бинарный файл
brew install --HEAD WindustH/tap/calibre-tui   # последняя версия из git
```

К каждому релизу на GitHub приложены готовые бинарные файлы для Linux (x86_64), macOS (Apple Silicon) и Windows (x86_64).

Для сборки из исходников нужен Rust, а в Linux ещё и пакет разработки SQLite (например, `libsqlite3-dev`):

```bash
git clone --recursive https://github.com/WindustH/calibre-tui.git
cd calibre-tui
cargo build --release
./target/release/calibre-tui
```

## Использование

Запустите `calibre-tui`. Библиотека Calibre находится автоматически; если этого не произошло, укажите `library_path` в `config.toml`.

- Вводите текст для поиска; `Backspace` удаляет символ.
- `Up` / `Down` или колесо мыши — перемещение; `PgUp` / `PgDn`, `Home` / `End` — переходы.
- `Tab` — выбрать книгу под курсором или снять выбор. `Ctrl+A` выбирает все результаты, `Ctrl+X` очищает выбор.
- `Enter` — открыть выбранные книги или книгу под курсором, если ничего не выбрано.
- `Ctrl+Y` — скопировать их пути в буфер обмена.
- `Ctrl+P` — вывести их пути и выйти.
- `Ctrl+S`, затем буква — сортировка (`t` название, `a` авторы, `s` серия, `f` форматы, `g` теги; заглавная буква — по убыванию).
- `Ctrl+T` — командная строка, например `sort authors asc title desc`.
- `F1` — показать все сочетания клавиш.
- `Esc` или `Ctrl+C` — выход.

С флагом `--exit-on-open` программа завершается после открытия книг.

Пути выводятся в stdout по одному на строку, а интерфейс остаётся в терминале, поэтому их удобно использовать в скриптах:

```bash
zathura "$(calibre-tui)"                    # открыть одну книгу
calibre-tui | xargs -d '\n' -r cp -t ~/usb  # скопировать выбранные книги (GNU xargs)
```

## Настройка

При первом запуске создаются четыре файла со значениями по умолчанию и комментариями:

- `config.toml` — путь к библиотеке, программы для форматов, транслитерация при поиске
- `layout.toml` — колонки, их порядок и ширина, а также поля для поиска
- `keymap.toml` — сочетания клавиш
- `theme.toml` — цвета

Они находятся в `~/.config/calibre-tui/` в Linux, `~/Library/Application Support/calibre-tui/` в macOS и `%APPDATA%\calibre-tui\` в Windows. Если обновление добавляет новые настройки, они дописываются со значениями по умолчанию. Файл, который больше не удаётся прочитать, сохраняется как `<имя>.bak-<время>` и заменяется значениями по умолчанию.
